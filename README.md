# Syringe Pump Controller

Firmware for a syringe pump with an **STM32F103C8T6 (Blue Pill)**, an **A4988 stepper driver** and a **Nextion touch screen**.
The user sets the syringe diameter and the flow rate on the screen. The firmware calculates the motor speed and pushes the syringe at that rate.

Written in **C++** (classes split into `.hpp` + `.cpp`) on top of the STM32 HAL, made with **STM32CubeIDE**.

## Features

- Flow rate in **mL/min**, **mL/h** or **µL/min**, with 2 decimals
- Syringe diameter input in mm
- Start / stop; the motor turns in one direction only (DIR fixed, pushes forward)
- Jog (move while the button is held) with a soft start and a safety timeout
- Last settings (diameter, flow, unit) saved in flash and loaded at power-on
- Hardware-independent logic, tested on a PC (see [PC tests](#pc-tests))

## Hardware

| Part | Notes |
|---|---|
| STM32F103C8T6 Blue Pill | 72 MHz, programmed with an ST-LINK V2 (SWD) |
| A4988 stepper driver | STEP / DIR / ENABLE / MS1–MS3 / RESET from the MCU |
| Stepper motor + lead screw | moves the syringe pusher |
| Nextion NX4832K035 (3.5", 480×320) | talks over UART |

### Pins

| Pin | Use |
|---|---|
| PA9 / PA10 | USART1 TX / RX → Nextion (115200 baud) |
| PB4 | STEP (TIM3 CH1, PWM) |
| PB3 | DIR (always LOW = forward) |
| PB9 | ENABLE |
| PB8 / PB7 / PB6 | MS1 / MS2 / MS3 (microstep) |
| PB5 | RESET |
| PA15 | driver control output |
| PC13 | on-board LED |
| PA13 / PA14 | SWD (SWDIO / SWCLK) |

## Screen protocol

The screen sends one text line per command. The firmware answers with normal Nextion commands (ending with `FF FF FF`).

| Command | Meaning |
|---|---|
| `DIA<value>` | syringe diameter in mm, e.g. `DIA19.20` |
| `FLW<value>` | flow rate in the chosen unit, e.g. `FLW0.08` |
| `UNT0` / `UNT1` / `UNT2` | unit: mL/min / mL/h / µL/min |
| `RUN` / `STP` | start / stop |
| `JOG` / `JST` | jog start / jog stop |

Any other command (e.g. the old `FWD` / `REV`) gives "unknown command". Screen texts are in Turkish. The Nextion project file (`.HMI`) is not in this repo yet.

## Code structure

| File (`Core/Inc`, `Core/Src`) | What it does |
|---|---|
| `app` | main loop, connects all parts |
| `pump_calculator` | diameter + flow → pulses per mL → step frequency |
| `pump_controller` | pump states (stop / run / jog) |
| `stepper_driver`, `motor_interface` | A4988 control over TIM3 PWM |
| `line_reader`, `command_parser` | UART bytes → lines → commands |
| `command_handler` | runs a command and updates the screen |
| `nextion_screen`, `nextion_command`, `screen_text`, `screen_interface` | text and commands for the Nextion |
| `settings_store`, `stm_flash`, `flash_interface` | save / load settings in flash |

`main.c` and the other HAL files are generated by STM32CubeMX (`syringe_pump_b.ioc`).

## Build

1. Open STM32CubeIDE and choose **File → Import → Existing Projects into Workspace**.
2. Select this folder and import the project.
3. Build it (hammer icon), then flash it with an ST-LINK (Run / Debug).

## PC tests

The logic classes do not use the HAL, so they can be tested on a PC with `g++`. Example:

```bash
cd pc_test
g++ -std=c++17 -Wall -Wextra -I../Core/Inc test_command_parser.cpp ../Core/Src/command_parser.cpp -o test_command_parser && ./test_command_parser
```

Other tests: `test_pump_calculator`, `test_pump_controller`, `test_screen_text`, `test_command_handler`, `test_settings_store`. Each one needs its own `.cpp` files from `Core/Src`.
